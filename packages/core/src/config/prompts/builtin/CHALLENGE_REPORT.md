# 报告生成模板 

> 生成之后提供给 challenge_submit_report 的 report参数
> 

## 字段说明

- `TARGET` 测试目标

## 模板

```markdown
# 针对 {TARGET} 的渗透测试报告

## 1. 目标搜集的基础信息

...服务器基本信息（容器、开发语言等）...
...应用架构...

## 2. 漏洞/风险情报

### 2.1 xxx 漏洞/风险

...漏洞描述...
...复现（可以是数据包、curl命令、脚本等）...

### 2.2 xxxx

...

## 3. 修复建议

1. ...
2. ...
3. ...
....
```
